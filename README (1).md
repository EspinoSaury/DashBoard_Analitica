# Dashboard Farmacias del Valle

## Ejecutar localmente
1. Instala Python 3.10 o superior.
2. Abre una terminal en esta carpeta.
3. Ejecuta: `pip install -r requirements.txt`
4. Ejecuta: `streamlit run app.py`
5. Se abrirá el dashboard en el navegador.

## Contenido
- 3 KPIs con comparación contra periodo anterior de igual duración.
- Filtros por periodo, categoría, producto y promoción.
- Tendencia de ingresos, ingresos por categoría, top 10 por unidades y distribución de stock.
- Anotación narrativa dinámica y tabla de detalle.
